# Product

## Register

product

## Users

Engineers comparing HTTP server performance across Bun, TypeScript frameworks, and OCaml runtimes.

## Product Purpose

Run controlled local benchmarks and make throughput, latency, memory, CPU use, and errors easy to compare.

## Brand Personality

Technical, direct, and evidence-led.

## Anti-references

Avoid decorative SaaS dashboards, oversized metric cards, unexplained scores, and visual effects that compete with the data.

## Design Principles

- Put measured data before interpretation.
- Keep benchmark conditions visible beside results.
- Make framework and runtime comparisons easy to scan.
- Distinguish smoke checks from publishable benchmark runs.

## Accessibility & Inclusion

Meet WCAG AA contrast, support keyboard navigation, preserve readable data at narrow widths, and respect reduced-motion preferences.
